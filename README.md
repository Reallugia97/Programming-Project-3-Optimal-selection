# Programming-Project-3-Optimal-selection


## Prerequisites

* [Git](https://git-scm.com/)
* JDK 17 or newer

## Installation

1. **Clone the repository: (If you don't already have the zip file)**
   ```cmd
   git clone https://github.com/Reallugia97/Programming-Project-3-Optimal-selection.git
   ```
2. **Enter username and password token (if required)**

## Running the Application

1. **Import files into Eclipse:**
   * File -> Import -> General -> Existing Projects into Workspace.
   * Select the zip file or root directory of cloned repo.

2. **Navigate to the src folder**

3. **Navigate to project3 package**

4. **Run _____________**
